**Added:**

* A workflow to build C extension wheels with cibuildwheel. Projects
  that set ``build_c_ext_with_cibw: true`` need a ``[tool.cibuildwheel]``
  table in ``pyproject.toml``.
* ``build_c_ext_with_cibw`` input (default ``false``) to switch C extension
  builds to the cibuildwheel workflow.
